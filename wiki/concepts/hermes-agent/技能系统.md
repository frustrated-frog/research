# 技能系统

> 按需加载的程序性知识，Agent 可以自创建、自改进

## 核心定位

技能是**按需加载的知识文档**，回答"怎么做X"这类程序性问题，和回答"X是什么"的声明性记忆（MEMORY/USER）互补。

## 记忆 vs 技能

| | 记忆（MEMORY/USER） | 技能（Skills） |
|--|--|--|
| 性质 | 声明性 | 程序性 |
| 回答 | "X是什么" | "怎么做X" |
| 格式 | 事实片段，1-3句 | 步骤、命令、验证方法 |
| 容量 | 硬性上限（2200/1375字符） | 无限制 |
| 粒度 | 原子事实 | 完整工作流 |
| 触发 | 用户透露偏好时 | 复杂任务完成/试错/方法纠正时 |

**典型记忆**："用户用 pnpm，不喜欢 npm"

**典型技能**：
```markdown
## 何时使用
用户要求安装 Node.js 依赖。

## 步骤
1. 检查是否有 pnpm
2. 运行 `pnpm install`，不是 `npm install`

## 陷阱
- 不要默认用 npm install
```

## SKILL.md 格式

每个技能一个 `SKILL.md`，包含两部分：

```yaml
---
name: my-skill
description: 简短描述（供补全用）
version: 1.0.0
platforms: [linux, macos]  # 可选：限制操作系统
metadata:
  hermes:
    tags: [python, automation]
    category: devops
    fallback_for_toolsets: [web]  # web工具集存在时隐藏，不存在时显示
    requires_toolsets: [terminal] # 只有terminal可用时才显示
---
# 技能标题

## 何时使用
触发条件描述。

## 步骤
1. ...
## 陷阱
- ...
```

## 六种操作

| 操作 | 用途 | 说明 |
|------|------|------|
| **create** | 从零创建新技能 | 需要完整 SKILL.md |
| **patch** | 定向修改 | **首选**，只传变化片段，最省 token |
| **edit** | 整体结构重写 | 需要完整内容，token 消耗大 |
| **delete** | 删除技能 | — |
| **write_file** | 添加/更新参考文件 | references/ 下的文件 |
| **remove_file** | 删除参考文件 | — |

**为什么 patch 优于 edit**：edit 需要 LLM 提供完整 SKILL.md 内容（约 2,000+ tokens），patch 只需提供变化的片段（约 10-50 tokens）。在工具调用受限的上下文里，这个差异巨大。

## 模糊匹配

LLM 提供的 `old_string` 和文件中实际文本可能有细微差异（空格、缩进）。`fuzzy_match.py` 引擎自动处理这些差异，而不是让 LLM 提供精确匹配的字符串。

## 条件激活

### Fallback Skills
```yaml
fallback_for_toolsets: [web]  # web工具集存在时隐藏，不存在时显示为后备
```

例如内置的 duckduckgo-search：当 FRCRAWL_API_KEY 设置后 web 工具集可用，duckduckgo 技能自动隐藏。

### 平台限制
```yaml
platforms: [macos]  # 仅 macOS 显示
```

## 自创建时机

Agent 在以下情况自动创建/更新技能：
- 完成复杂任务（5+ 工具调用）后
- 遇到错误但找到解决路径后
- 用户纠正了它的方法后
- 发现非平凡工作流后

## 安全扫描

Agent 创建的技能和从 Hub 安装的技能接受同等安全检查：数据外泄、提示注入、破坏性命令、供应链信号。危险 verdict 会拦截并删除已创建的目录。

技能修改后，自动清除 AIAgent 的技能系统提示缓存，强制重建以反映最新内容。

## 技能 Hub 生态

| 来源 | 说明 |
|------|------|
| builtin | Hermes 内置，始终信任 |
| official | optional-skills/，内置信任 |
| trusted | openai/skills、anthropics/skills，宽松策略 |
| community | skills.sh、自定义 GitHub，--force 可覆盖警告 |

## 三级渐进加载

```
Level 0: skills_list()
  → [{name, description, category}, ...]

Level 1: skill_view(name)
  → 完整内容 + 元数据

Level 2: skill_view(name, path)
  → references/ 下的具体参考文件
```

不需要时不出现，需要时只加载相关部分，用完即释放。
