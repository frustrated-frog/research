# 工具架构

> 47 个内置工具，20 个工具集，MCP 动态扩展

## 工具注册机制

工具在 import 时自注册到 `tools/registry.py`，每个工具文件调用 `registry.register()`。添加新工具需要在 `model_tools.py` 的 `_discover_tools()` 中 import。

## 内置工具分类

| 类别 | 代表工具 | 用途 |
|------|---------|------|
| Web | web_search, web_extract | 搜索和页面内容提取 |
| 终端 & 文件 | terminal, read_file, patch, write_file | 命令执行和文件操作 |
| 浏览器 | browser_navigate, browser_snapshot, browser_vision | 自动化浏览器操作 |
| 媒体 | vision_analyze, image_generate, text_to_speech | 多模态分析和生成 |
| Agent 编排 | todo, clarify, execute_code, delegate_task | 任务规划、子Agent委托 |
| 记忆 & 召回 | memory, session_search | 持久记忆和会话搜索 |
| 定时 & 投递 | cronjob, send_message | 定时任务和消息发送 |
| 集成 | ha_*, MCP tools, rl_* | Home Assistant、MCP、RL训练 |

## 工具集（Toolsets）

工具集是工具的逻辑分组，支持按平台启用/禁用：

```bash
hermes chat --toolsets "web,terminal"  # 仅启用 web 和 terminal 工具集
hermes tools  # 查看所有可用工具
```

常见工具集：web、terminal、file、browser、vision、image_gen、skills、tts、todo、memory、session_search、cronjob、code_execution、delegation、clarify。

## 终端后端

终端工具支持 6 种执行环境：

| 后端 | 说明 | 使用场景 |
|------|------|---------|
| local | 本机执行（默认） | 开发、可信任务 |
| docker | Docker 容器隔离 | 安全隔离、可重现 |
| ssh | 远程服务器 | 沙箱、隔离 Agent 自身代码 |
| singularity | HPC 容器 | 集群计算、无 root |
| modal | 云端无服务器 | 无服务器、弹性扩展 |
| daytona | 云沙箱工作区 | 持久远程开发环境 |

**容器安全加固**：只读根文件系统、丢弃所有 Linux capabilities、无 privilege escalation、PID 限制（256 进程）、完整 namespace 隔离。

## 后台进程管理

```python
terminal(command="pytest -v tests/", background=True)
# 返回: {"session_id": "proc_abc123", "pid": 12345}
```

管理操作：list（显示运行中进程）、poll（检查状态）、wait（阻塞直到完成）、log（获取完整输出）、kill（终止进程）、write（发送输入）。

PTY 模式（pty=True）支持交互式 CLI 工具如 Codex 和 Claude Code。

## MCP 集成

MCP（Model Context Protocol）允许连接外部 MCP 服务器扩展工具能力：

```yaml
mcp_servers:
  github:
    command: npx
    args: ["-y", "@modelcontextprotocol/server-github"]
    env:
      GITHUB_PERSONAL_ACCESS_TOKEN: "ghp_xxx"
```

特点：动态工具发现、按需过滤 MCP 工具、安全扩展 Hermes 能力。
