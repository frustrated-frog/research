# 功能清单文件

**功能清单文件（Feature List）** 是 harness 的核心数据文件——机器可读的功能状态记录，驱动整个任务调度和验证流程。

## 在系统中的位置

```
项目目录/
├── features.md 或 features.json   ← 功能清单（机器可读）
├── PROGRESS.md                     ← 进度总览（可读性优先）
└── docs/
    └── feature-template.md         ← 功能项模板（可选）
```

## 文件格式示例

```json
{
  "features": [
    {
      "id": "F01",
      "behavior": "POST /api/users returns 201 with user object",
      "verification": "curl -X POST /api/users -d '{"email":"test@example.com"}' | jq '.status == 201'",
      "state": "passing",
      "evidence": "commit abc1234, 15 tests passing",
      "created": "2026-01-15"
    },
    {
      "id": "F02",
      "behavior": "User can reset password via email link",
      "verification": "E2E test: click reset link → enter new password → login succeeds",
      "state": "active",
      "evidence": "Partial implementation: API done, email service not configured",
      "blocked_by": null
    }
  ]
}
```

## 状态转移规则

```
not_started → active → passing (验证通过)
                   → blocked (依赖未满足)
active → blocked (遇到阻塞)
blocked → active (阻塞解除)
```

只有验证命令执行成功才能从 active → passing。
