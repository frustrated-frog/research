# 冲刺合同

**冲刺合同（Sprint Contract）** 是 Anthropic 三 agent 架构中的核心工具——Generator 和 Evaluator 在每个 sprint 开始前协商的短期协议，明确"做完"的标准。

## 在系统中的位置

```
项目目录/
├── features.md               ← 功能清单（总览）
├── sprint-contracts/        ← 冲刺合同目录
│   ├── F03-dark-mode.md     ← 当前 sprint 的合同
│   └── F04-payment.md
└── ...
```

## 合同结构

```markdown
# 冲刺合同: F03 暗色模式支持

## 范围
- 修改 src/theme/ThemeToggle.tsx
- 更新 src/styles/variables.css 全局 CSS 变量
- 添加 dark mode 端到端测试

## 验收标准
- [ ] 主题切换组件可用
- [ ] 所有组件支持暗色模式
- [ ] 主流程端到端测试通过
- [ ] 无样式闪烁 (FOUC)
- [ ] WCAG AA 对比度合规（按钮文本 4.5:1）

## 排除项
- 不处理打印样式
- 不修改第三方组件库（使用覆盖样式）

## 风险
- 已知：第三方图表库需要单独处理（已创建 F05）

## 签署
- Generator: [签名]
- Evaluator: [签名]
- Date: 2026-05-14
```

## 使用场景

1. **Generator 按合同施工**：不按感觉，按合同
2. **Evaluator 按合同验收**：不主观判断，按标准
3. **歧义时回查合同**："这个问题算不算超范围？"
