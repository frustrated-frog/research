# 网关系统

> 文件：gateway/run.py，~5,800 行 | 消息平台统一接入

## 定位

Gateway 是 Hermes 的**消息平台网关**，负责：
- 14+ 平台适配器
- 统一会话路由
- 用户授权（allowlist + DM pairing）
- Slash 命令分发
- Hook 系统
- Cron 定时
- 后台维护

## 核心文件

```
gateway/
├── run.py              # GatewayRunner，消息分发
├── session.py          # SessionStore，会话持久化
├── delivery.py         # 出站消息投递
├── pairing.py          # DM pairing 授权
├── hooks.py            # Hook 发现和生命周期
├── mirror.py           # 跨会话消息镜像
├── status.py           # Token 锁，profile 级进程跟踪
├── builtin_hooks/      # 始终注册的 hooks
└── platforms/          # 14 个平台适配器
```

## 数据流

```
平台事件 → Adapter.on_message()
  → GatewayRunner._handle_message()
  → 授权用户
  → 解析会话 key
  → 创建带会话历史的 AIAgent
  → AIAgent.run_conversation()
  → 通过适配器投递响应
```

## 授权机制

- **Allowlist**：基于配置的允许用户列表
- **DM Pairing**：新用户首次 DM 时需要配对授权
- **Pairing Store**：配对信息存储在 `~/.hermes/pairing/`

## Hook 系统

Hook 机制允许自定义行为：
- 发现：gateway/hooks.py
- 生命周期事件
- 内置 hooks 在 builtin_hooks/

## Cron 集成

Gateway 内置 Cron 引擎：
- Scheduler tick 检查到期任务
- 加载 jobs.json 中的到期任务
- 创建新的 AIAgent（无历史）
- 附加技能作为上下文
- 运行任务 prompt
- 投递响应到目标平台
- 更新任务状态和下次运行时间
