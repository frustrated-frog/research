# 会话存储

> 文件：hermes_state.py + gateway/session.py | SQLite + FTS5

## 存储架构

SQLite 数据库（~/.hermes/state.db）存储所有会话数据：
- **FTS5 全文搜索**：支持自然语言检索历史会话
- **会话血缘追踪**：压缩后的父子会话关系
- **按平台隔离**：不同平台会话独立
- **原子写入**：竞争处理

## 核心能力

### 会话持久化

```bash
hermes sessions list  # 浏览所有历史会话
```

每个会话包含：
- 完整消息历史
- 模型和工具配置
- 时间戳和元数据

### 会话搜索

Agent 使用 `session_search` 工具搜索历史会话：
- FTS5 全文搜索
- Gemini Flash 摘要
- 找到讨论过的具体内容

### 压缩与会话血缘

当上下文超过阈值时：
1. 对话被压缩（摘要中间轮次）
2. 创建新的压缩会话
3. 保留父子关系追踪

## 与记忆系统的区别

| 特性 | 会话存储 | 固定记忆（MEMORY.md/USER.md） |
|------|---------|------------------------------|
| 容量 | 无限 | ~1,300 tokens |
| 速度 | 搜索+摘要 | 即时 |
| 用途 | 查找过去讨论 | 始终可用的关键事实 |
| 管理 | 自动 | Agent 人工策展 |
| Token 成本 | 按需 | 每会话固定 |

## 数据位置

```
~/.hermes/
├── state.db          # SQLite 数据库（FTS5）
├── sessions/         # 会话 JSONL 文件
├── memories/         # MEMORY.md / USER.md
└── memories/         # 技能文件
```
