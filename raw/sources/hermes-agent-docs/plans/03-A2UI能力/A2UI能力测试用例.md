## 验收标准

- P0 用例全部通过，无阻塞缺陷。
- P1 用例通过率不低于 95%，未通过项已有明确修复计划。
- 页面生成、编辑、删除链路完整可用。
- 智能体不会将闲聊或信息查询误识别为高风险页面编辑操作。
- 删除楼层、删除画布等破坏性操作具备确认、撤销或可恢复能力中的至少一种。
- 生成结果与提示词约束一致，尤其是首页结构、文字样式、素材新增和楼层操作。
